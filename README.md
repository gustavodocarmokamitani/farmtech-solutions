## 📜 Descrição Do Projeto

O **FarmTech Solutions** é uma solução de inteligência computacional para o agronegócio que atua na intersecção entre monitoramento IoT e modelos preditivos de Inteligência Artificial. O projeto atende à necessidade crítica de reduzir as perdas na colheita mecanizada e mitigar riscos operacionais em parceria com a **Sompo Seguros**.

Na **Fase 3**, a solução evoluiu de um sistema de logs local para uma **Plataforma Preditiva Integrada**:
1. **Persistência Relacional Robustecida:** Ingestão estruturada de dados de telemetria diretamente no banco de dados corporativo **Oracle Cloud FIAP**.
2. **Dashboard Operacional Dinâmico:** Interface web desenvolvida em **Streamlit** para visualização e simulação em tempo real de sensores de solo e clima.
3. **Motor de Machine Learning:** Integração de um algoritmo de classificação **Random Forest Classifier** (`scikit-learn`) treinado com bases históricas para prever em tempo real a cultura agrícola ideal com base nas características de solo e clima do ecossistema mapeado.
